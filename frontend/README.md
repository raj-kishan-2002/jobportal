# Job Portal - Frontend

A modern job portal frontend built with React and Vite.

## Features

- User authentication
- Student and recruiter roles
- Job search and filtering
- Job application system
- Company management
- Profile management
- Responsive UI

## Tech Stack

- React
- Vite
- React Router
- Redux Toolkit
- Tailwind CSS
- Axios
- Shadcn UI

## Setup

```bash
npm install
npm run dev
